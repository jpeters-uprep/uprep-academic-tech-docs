UPrep provides a range of officially licensed and recommended software — see
[Fully Supported Software](/software/fully-supported) and
[Recommended Free Software](/software/recommended-free) for what's already
available to you.

## VR

UPrep has Quest 3 headsets available for classroom and Community Time use. See
[VR Software](/software/vr) for the apps available on them.

## Something Not Listed?

If a class needs an app or extension that isn't already supported, ask your
teacher — new software for a class or project is requested by faculty, not
students directly. See [Software](/software) for the full picture of what's
supported, IT-supported, and unsupported.
