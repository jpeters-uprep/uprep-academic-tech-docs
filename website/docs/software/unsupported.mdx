Software that is not listed as [Fully Supported](/software/fully-supported) or
[Recommended Free Software](/software/recommended-free) is not officially
sanctioned or supported by UPrep. Please ensure you follow data safety and
privacy guidelines when using it, including not putting student data in
unapproved software. Faculty and Staff may request support for additional
software by following the
[Software Process](/faculty/teacher-software/software-process).
