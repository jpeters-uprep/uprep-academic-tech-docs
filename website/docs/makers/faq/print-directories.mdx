## Question

Where do I find models online to 3D print?

## Answer

We encourage creating your own models using TinkerCAD or Fusion. If you'd like
to print someone else's models, the best online sources are
[printables.com](https://www.printables.com/) and
[Maker World](https://makerworld.com/)
