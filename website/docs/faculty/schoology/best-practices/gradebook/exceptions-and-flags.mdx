Hover over any gradebook cell and click the flag icon to apply an exception.
Exceptions let you communicate something about a student's submission status
without changing the raw score. Schoology currently offers six exception types:

- **Missing** — whether this counts as a zero in grade calculations is a
  per-class setting, not a single UPrep-wide default. Check your own course's
  Final Grade Settings, or ask June if you're not sure how yours is configured.
- **Incomplete** — stays on the student's Overdue list and does not affect the
  grade calculation. Use this if you're accepting a late submission but don't
  want the gap to count against the student in the meantime.
- **Exempt** (also shown as **Excused** in some places in Schoology's own UI —
  both terms are in current use, not an old-vs-new distinction) — removes the
  item from grade calculations entirely, so it neither helps nor hurts the
  student's grade.
- **Absent**, **Late**, and **Collected** — additional exceptions to communicate
  a submission's status; use whichever best describes it.

**What actually clears an item from a student's Overdue list:** a submission, a
manually entered grade, an Excused or Missing exception, the course being
archived, or Enable Submission being turned off for that assignment. Absent,
Late, and Collected do **not** clear an Overdue notification on their own.

**A data-loss caution:** depending on an admin-level Feature Option, adding an
exception to an assignment _after_ a score has already been entered can clear
that score. If you're not sure how UPrep's instance is configured, ask June
before assuming either way.

See Schoology's
[Use Exceptions in the Gradebook documentation](https://uc.powerschool-docs.com/en/schoology/latest/use-exceptions-in-the-gradebook)
for full definitions.
