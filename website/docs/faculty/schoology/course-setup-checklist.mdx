A genuine checklist, in the order you'd actually do the work. Each item links to
the page that explains it — print this page, or just work down it, at the start
of a term.

- ☐ Syllabus posted and easy to find — see
  [Schoology Requirements](/faculty/schoology/requirements)
- ☐ Folder structure created (three levels or fewer) — see
  [Course Organization](/faculty/schoology/best-practices/course-organization)
- ☐ Common Resources / Toolkit folder at the top of the course — see
  [Course Organization](/faculty/schoology/best-practices/course-organization)
- ☐ Grade Setup configured for your division — see
  [Schoology Requirements](/faculty/schoology/requirements) for the exact
  settings and [Gradebook](/faculty/schoology/best-practices/gradebook) for why
  they matter
- ☐ Categories and weighting set before the term starts — see
  [Gradebook](/faculty/schoology/best-practices/gradebook)
- ☐ Assessment due dates calendared and aligned to class periods — see
  [Due Dates and Calendaring](/faculty/schoology/best-practices/due-dates-and-calendaring)
- ☐ Submissions turned on only where you want electronic submission — see
  [Assignments and Materials](/faculty/schoology/best-practices/assignments-and-materials)
- ☐ Assignment resources attached directly — see
  [Assignments and Materials](/faculty/schoology/best-practices/assignments-and-materials)
- ☐ Assessments cross-posted to the grade-level Workload Calendar — see
  [Workload Calendar](/faculty/schoology/best-practices/workload-calendar)
- ☐ Rotating or linked sections: Grading Groups configured — see
  [Schoology Requirements](/faculty/schoology/requirements)
- ☐ Roster matches Veracross — see
  [Schoology and Veracross](/faculty/schoology/schoology-and-veracross)

**Heads up:** if your course was created from a template, it may already have
content and settings applied automatically (Schoology's Course Template
Distribution feature) — check what's already there before assuming a blank
slate.
