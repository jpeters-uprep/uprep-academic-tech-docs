We have many [software tools](/software) available at UPrep for students,
faculty, and staff. Some software is officially licensed by UPrep, including
Schoology, Veracross, Adobe Creative Cloud, Microsoft 365 and Copilot, Canva,
Autodesk, and more.

We have an annual process for requesting licenses for software that is not
currently supported:

In mid-semester two, department chairs will notify their departments that we
have started the process of reviewing software requests for the upcoming school
year.

A deadline for requests will be set in ILT and faculty will be notified of the
deadline.

Department chairs will gather requests and put information on a spreadsheet.

All requests will be reviewed in ILT. Faculty will be notified of decisions by
department chairs.

ILT will share the spreadsheet with Amy (for budgeting purposes) and June (FYI
purposes).

We are in the process of moving away from reviewing requests outside of this
process. Exceptional circumstances should be requested through department
chairs, who should talk to division heads.

This annual process is for tools that need a **new paid license**. If you just
need a specific **free app installed** on MS student Chromebooks for a class or
test — or an app already covered by an existing UPrep subscription — that's a
faster, separate process; see
[Requesting an App for Class or Testing](../app-install-requests). For a
**Chrome extension** pushed to student browsers specifically, see
[Requesting a Chrome Extension for Student Laptops](../extension-requests).
