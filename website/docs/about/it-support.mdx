IT Support and Academic Technology work closely together, but are not the same
department. IT Support covers technical issues for UPrep including WiFi,
printing, loaner devices, account setup (including Microsoft and Google login),
device setup, passwords, and phones.

Visit the [IT Support page](https://support.universityprep.org/) for more
information.
