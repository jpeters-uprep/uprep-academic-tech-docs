A reusable list of 2D sketch objects to practice with in Fusion. Pick whatever
category interests you and work at whichever tier matches how comfortable you
are. All of these are **2D sketch only** — no extrude yet; that comes later in
the unit.

See [Fusion Training](/makers/fusion-training) for video walkthroughs of the
tools these objects use, and [Fusion in This Class](../fusion-in-this-class) for
access, files, and units. Not sure which tool fits a given object? Check the
[Fusion Sketch Tools quick reference](../fusion-sketch-tools).

## How to use this

- Every object has a version at all three tiers, so you can move up in
  complexity on the _same_ object instead of switching to something unrelated —
  start a robot head at Floor Tier and keep adding to that exact sketch as you
  get more comfortable, rather than starting over on a different shape.
- **Floor Tier** is a closed profile with 3+ connected lines, 2+ dimensional
  constraints, and 1+ geometric constraint — start here if you're still building
  basic fluency.
- **Stretch Tier 1** adds one new mechanic — usually tangent arcs, a cutout, or
  an equal/symmetric constraint — try this once the Floor Tier version feels
  comfortable.
- **Stretch Tier 2** combines several mechanics (nested cutouts, repeated or
  patterned features, symmetry across a centerline) — reach for this if you're
  moving fast and want a real design problem instead of more of the same.
- Categories are deliberately mixed (sports, gaming, vehicles, architecture,
  music, everyday objects) — pick whatever interests you, there's no requirement
  to work through them in order.

## Tips

- **Tangent arcs** show up the most across Stretch Tier 1 and 2 (wheel wells,
  ramps, guitar bodies, rocket nose cones) — it's worth getting comfortable with
  them since they come up constantly.
- **Nested cutouts** (a closed profile inside a closed profile) are the second
  most common mechanic — houses, picture frames, phone cases, windows — and
  preview work you'll do later in the course when you design a CNC-cut project —
  where the clearance between the two profiles stops being cosmetic and starts
  deciding whether parts fit. See [Tolerance and Fit](../tolerance-and-fit).
- **Patterns** (Rectangular/Circular Pattern) show up a lot at Stretch Tier 2 —
  screw holes, rivets, stamps, mullions, crenellations. A clean repeated feature
  is one of the clearest signs your sketch is actually fully constrained, not
  just "looks right by luck."
