Reference pages for the Design and Fabrication class. These are meant to be
looked up mid-project — when you're stuck on an export, unsure what clearance to
leave, or about to run a machine for the first time — not read start to finish.

Every tool we use is already documented by the company that makes it, and their
documentation is better than anything we'd write from scratch. So these pages
cover what's true of _our_ shop and _this_ class — our machines, our workflow,
what we've learned the hard way — and link out to the manufacturer for
everything else. When a page sends you to Autodesk, Bambu Lab, Carbide 3D, or
Silhouette, that's on purpose.
